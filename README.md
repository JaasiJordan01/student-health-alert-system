# University Health Alert & Student Tracking System

This repository contains a GitHub Pages-ready static prototype for the student health alert system.

## Pages deployment
The static site files are:
- `index.html`
- `styles.css`
- `script.js`
- `data/sample_data.json`

Open the repo in GitHub and enable Pages from Settings > Pages.
